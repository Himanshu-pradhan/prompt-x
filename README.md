# PROMPT-X

An AI-powered project recommendation and mentoring platform that helps final-year students discover the right project based on their skills, interests and constraints.

## Features

- **Personalized Recommendations:** Analyzes student's branch, skills, interests, team size, and time constraints.
- **Match Score Engine:** Calculates a percentage match for each project based on compatibility.
- **Detailed Project Overviews:** Displays required tech stack, modules, and innovation ideas.
- **AI Mentor:** Contextual demo chat mentor to answer common student questions about the project.
- **Modern UI:** Responsive, beautiful dark-themed design built with CSS and React.

## How to Run

1. Clone or download the repository.
2. Ensure you have Node.js installed.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser to the local URL (usually `http://localhost:5173/`).

## Tech Stack
- React
- Vite
- React Router DOM
- Lucide React (Icons)
- Custom CSS (Dark Theme, Glassmorphism)
